> **Sinais de Inclusão API** é o serviço backend responsável pelo gerenciamento de dados, autenticação de usuários e fornecimento dos conteúdos programáticos para o aplicativo mobile de aprendizado da Língua Brasileira de Sinais (Libras).

---

## 🏛️ Contexto Institucional e Impacto Social

Esta API compõe a infraestrutura tecnológica do projeto **Sinais de Inclusão**, desenvolvido de forma integrada às atividades do **Instituto Federal de Educação, Ciência e Tecnologia de São Paulo (IFSP)**.

---

## 🛠️ Tecnologias Utilizadas

*   **Runtime:** [Node.js](https://nodejs.org/) (Ambiente de execução Javascript)
*   **Linguagem:** [TypeScript](https://www.typescriptlang.org/) (Tipagem estática para maior segurança do código)
*   **Bundler/Runtime:** [tsx](https://github.com/privatenumber/tsx) & [esbuild](https://esbuild.github.io/) (Execução de TypeScript em alta performance)
*   **Banco de Dados & Auth:** [Supabase](https://supabase.com/) / PostgreSQL (Persistência, Edge Functions e controle de sessões)
*   **Documentação:** [Swagger JSDoc](https://swagger.io/) (Mapeamento automatizado dos endpoints)

---
